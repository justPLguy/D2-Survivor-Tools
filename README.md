## 🚨 IMPORTANT — LEADERBOARD WARNING

**USE THESE TOOLS FOR FUN AND PERSONAL EXPERIMENTATION ONLY.**

**MODIFYING YOUR SAVE MAY AFFECT YOUR CHARACTER'S ELIGIBILITY FOR LEADERBOARDS.**

Using these tools may result in:

- Your modified save being rejected by the game or leaderboard.
- Your character no longer appearing in leaderboard rankings.
- Loss of leaderboard progress or other unexpected consequences.
- Save corruption or loss of data if a modified save is invalid.

**There is NO guarantee that a modified save will remain eligible for leaderboard participation.**

The exact consequences depend on the game and its validation systems. These tools are not intended to provide leaderboard-safe modifications.

**Always back up your original save before using any tool. You are responsible for any changes made to your saves.**

## 🧰 Available Tools

### 🪙 D2 Survivors — Gold Editor

A lightweight, standalone utility for modifying the gold value in a *D2 Survivors* save.

**Current release:** `v1.0.0` — Initial Release

**Features:**

- Load a D2S1 save code by pasting it into the application.
- Load a save code from a text file.
- Change the gold value.
- Generate a modified save code.
- Copy the output to the clipboard.
- Export the modified save to a separate text file.
- Run as a standalone Windows executable or directly from Python.

**Important:** Using Gold Editor flags your save as edited. Runs using modified saves will not count toward the leaderboard.

**Downloads and documentation:**

- 📦 [Download Gold Editor v1.0.0](https://github.com/justPLguy/D2-Survivor-Tools/releases/tag/gold-editor-v1.0.0)
- 🌿 [View the Gold Editor branch](https://github.com/justPLguy/D2-Survivor-Tools/tree/tool/gold-editor)

The release includes `GoldEditor.exe` for Windows users who want to launch the application directly and `GoldEditor.py` for users who prefer running the Python source code.

Check the release page for download assets, requirements, instructions, and tool-specific limitations.

## 🗺️ Project Structure

This repository acts as the central hub for the D2 Survivor Tools collection.

- **`main`** — Project overview, documentation, general warnings, and links to individual tools.
- **Tool branches** — Each tool has its own dedicated development branch, keeping its code and changes separate from the rest of the project.
- **Releases** — Versioned downloads published independently for each tool.

Each tool can evolve independently without requiring every other tool to be updated.

Use the relevant tool branch and its Releases section to find source code, downloads, version information, and tool-specific instructions.
